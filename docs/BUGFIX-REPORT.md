# 网站 Bug 修复报告（2026-11-03）

依据 `网站Bug修复方案与开发提示词.docx` 的 8 个问题逐项处理。

## 1. 阅读模块（P0）

### 数据层

- 清理 OCR 产生的标题/页眉泄漏：选项里不再出现 `Passage Two`、`Section B`、`Part IV`、`Directions` 等后续内容。
- 修复选项缺失：
  - 2024.12 六级第二套 第 52 题补回 B。
  - 2025.06 六级第二套 第 5、14、17、19 题补回 C/D。
  - 2025.12 四级第一套 第 53 题补回 C。
  - 2024.12 四级第二套 第 47 题使用完整选项覆盖。
- 用本地词典 + `wordninja` 恢复 OCR 丢失的空格（如 `hasbecome` → `has become`、`toensure...` → `to ensure...`）。
- 选词填空/匹配/阅读 C 的空白标记、选项数量均通过 `content:validate`。

### 布局层

- `.reading-body` 增加 `overflow-wrap: anywhere`、`word-break: normal`。
- 阅读页外层 `overflow-x-hidden`，左右栏 `min-w-0`，题干/选项 `break-words`。
- 桌面端题目的右栏改为 sticky（`lg:sticky lg:top-20` + 最大高度 + 独立滚动），滚动长文章时题目保持可见；移动端仍上下堆叠。

## 2. 翻译模块（P1）

- 翻译入口已验证可用：`翻译` 导航 → 翻译题库 → `开始翻译` → 翻译编辑区正常出现。
- 阅读卡片新增「翻译练习」快捷按钮，点击直接进入对应试卷的翻译页。
- 首页快捷操作新增「翻譯練習」。
- 翻译原文清理：去掉答案页/阅读页泄漏内容，只保留题目说明 + 中文原文。
- 2024.12 六级第二套补回缺失的洋山港首句。

## 3. 听力模块（P1）

- 听力题库改为**按套题聚合**：一张卡片展示一整套听力，内部按顺序列出 News Report / Conversation / Passage / Recording。
- 每段显示题量、已答数量、语速、口音、TTS/音频档标记。
- 卡片底部「開始整套訓練」从第一段开始。
- 听力详情页新增「上一段 / 下一段」，支持按套顺序训练。
- 整套进度分母只统计 listening 题目，不再混入阅读/写作/翻译。

## 4. 四级/六级分流（P2）

- 顶部导航新增 CET-4 / CET-6 切换，状态保存在 `localStorage`。
- 切换后：
  - 阅读题卡只显示当前级别；
  - 听力题库只显示当前级别；
  - 翻译题库只显示当前级别；
  - 首页阅读卡只显示当前级别；
  - CET-6 使用橙色强调色，CET-4 使用原青绿色。
- 阅读卡片的分篇/题数、完成进度只统计 reading 题目；听力/翻译各自统计自己的题目。
