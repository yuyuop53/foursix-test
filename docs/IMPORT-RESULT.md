## 3. 为什么没有用网络搜索补听力

听力原文是完整的受版权保护文本。把第三方网站上的整段原文抓取并写入项目，不属于可以代做的范围。答案字母（例如 `1 A`、`26 L`）是事实性信息，但仅有答案也无法生成听力练习——站点需要 `transcript` 才能生成 TTS/逐句听写。

如果你的目标是继续补全：

1. **补答案**：2024.06 三套 DOCX、2024.12 六级第一套可以补客观题答案，然后导入阅读/写作/翻译（听力仍需原文）。
2. **补听力原文**：上述试卷需要你提供合法获得的原文，或提供 MP3 后改用音频后端（仍建议有原文用于逐句听写）。
3. **补题目卷**：2025.12 四级第二套需要完整题目 PDF/DOCX。
4. **2024.12 四级第一套**：需要补听力题干/选项和阅读正文；现有回忆版可继续作为听力原文来源。
