## 2. 建议补充文件的格式

建议统一放在项目里的私有目录（已被 `.gitignore` 排除，不会提交）：

```
D:\my-projects\cet-lab\content\private\cet-papers-supplement\
```

### 2.1 答案文件

每套一个 `.txt`，一行一题，或使用范围写法：

```text
# exam_2024-06_cet4_set1
1 A
2 C
3 B
...
55 D
```

也支持：

```text
1-5  ACBCD
6-10 BCDAB
```

### 2.2 听力原文文件

每套一个目录，按听力分组每个文件一段。**四级和六级分组不同**：

**四级（CET-4）8 段：**

| 文件 | 内容 | 题号 |
|---|---|---|
| `l1.txt` | News Report One | 1–2 |
| `l2.txt` | News Report Two | 3–4 |
| `l3.txt` | News Report Three | 5–7 |
| `l4.txt` | Conversation One | 8–11 |
| `l5.txt` | Conversation Two | 12–15 |
| `l6.txt` | Passage One | 16–18 |
| `l7.txt` | Passage Two | 19–21 |
| `l8.txt` | Passage Three | 22–25 |

**六级（CET-6）7 段：**

| 文件 | 内容 | 题号 |
|---|---|---|
| `l1.txt` | Conversation One | 1–4 |
| `l2.txt` | Conversation Two | 5–8 |
| `l3.txt` | Passage One | 9–11 |
| `l4.txt` | Passage Two | 12–15 |
| `l5.txt` | Recording/Lecture One | 16–18 |
| `l6.txt` | Recording/Lecture Two | 19–21 |
| `l7.txt` | Recording/Lecture Three | 22–25 |

> 段落编号以试卷上的 `Questions X to Y are based on...` 为准；不同套可能略有差异，补文件时在文件名或首行注明题号即可。

## 4. 补齐后的导入流程

1. 把答案文件、听力原文按上面的格式放进：
   `D:\my-projects\cet-lab\content\private\cet-papers-supplement\`
2. 我扩展 `scripts/import_exam_pdfs.py`：
   - 支持 DOCX 读取；
   - 支持 `--answers-file`（外部答案合并）；
   - 支持扫描页/图片页 OCR；
   - 区分 CET-4 / CET-6 的试卷 ID 与听力分组；
   - 写作/翻译参考、听力原文按现有 `exam.md` schema 输出。
3. 先 `--dry-run` 逐套检查题目数、答案覆盖率、听力段数；
4. 通过后写入 `content/exams/<exam_id>/exam.md`；
5. 运行 `npm run content:validate`，再用站点导入页/题库页抽查。
